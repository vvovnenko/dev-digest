# docs/plans

Work plans for the Claude Code agent harness (`.claude/agents/`, `.claude/skills/`) — kept so a later
session can execute or audit them without this conversation. Feature intent for the app lives in
`<pkg>/specs/`, not here.

- One plan per file: `YYYY-MM-DD-kebab-name.md`, with its research digest next to it as
  `YYYY-MM-DD-kebab-name-research.md`.
- A plan's `**Status:**` line says whether it is a draft, approved or done; the body is the record of
  what was decided and is not rewritten afterwards — later changes go in a dated note at the end.
